# 3D Model Collection

A comprehensive collection of 3D models including vehicles, buildings, furniture, plants, and various architectural elements.

## Contents

- **Vehicles**: Cars, parking structures
- **Buildings**: Apartments, temples, gas stations, tunnels
- **Furniture**: Sofas, beds, cupboards, waiting chairs
- **Appliances**: Air conditioners, ceiling fans, gas hobs, washing machines
- **Architecture**: Doors, elevators, stairs, street lights
- **Nature**: Tree models, low-poly plants
- **Interior**: TV wall panels, hospital waiting rooms

## Formats

- `.fbx` - Autodesk FBX format
- `.glb` - GL Transmission Format (Binary)
- `.blend` - Blender files
- `.skp` - SketchUp files
- `.max` - 3ds Max files
- `.obj` - Wavefront OBJ files

## Usage

These models can be used in various 3D applications, game engines, and visualization projects.
